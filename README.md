# ETStool
> 本`readme.md`更新于`正式版 1.2.2 (ver.r1.2.2)`

## 概述

这是一个作者因为嫌做e听说听力太麻烦所灵机一动，经过一番研究后做出来的小工具。

**主要功能**：
- 自动完成e听说的口语与选择题
- 自动分析识别到的试卷选择题答案并可一键复制
- 更详细的试卷包管理（查看、分析、解答、导出、删除）
- 接入 DeepSeek 分析题目详解
- 一站式嵌入操控e听说主程序
- 更多...

## 系统及环境配置要求

运行 etstool 推荐**硬件配置**：
- CPU: Intel Core i5 / AMD Ryzen 5 或同级以上
- RAM: 4 GB 及以上（推荐 8 GB 及以上以获得更好体验）
- GPU: 现代集成显卡或独立显卡
- ROM: 2 GB 及以上存储空间
- Display: 1920 x 1080 (1080p) 及以上
- Connection: 稳定的互联网连接
- Misc: 建议配合扬声器或耳机使用

**软件配置**:  
推荐使用 Windows 11 x64，向下兼容至 Windows 10 版本 1809。安装包中自带 Python 与 .NET 运行时组件，无需安装额外环境。

**请注意，不满足以上需求的硬件或软件也许仍可运行etstool，但可能无法正常使用所有功能，且由不满足的配置所引发的问题将不会被修复。**

## 安装与配置

本段将会介绍如何下载、安装及配置etstool。

0. **下载安装包或克隆仓库**:  
访问`https://github.com/LudanStudios/etstool.git`，使用 GitHub 下载仓库 zip 解压，或是直接下载 latest release 中的 msi 安装程序。  
如果已经安装 Git 版本管理系统，也可在终端中输入下列命令：
    ```pwsh
    git clone https://github.com/LudanStudios/etstool.git
    ```
    从而直接克隆仓库。

1. （可选）**配置凭据**
可通过手动填写 `DeepSeek API Key`, `AliyunTTS_RAM Name`, `AliyunTTS_RAM Secret`, `AliyunTTS_AppID` 从而配置口语凭据；也可直接导入csv文件。*无需自动口语可跳过。*

2. （可选）**配置驱动**
可安装 vb-cable 虚拟麦克风/扬声器驱动以实现自动口语。*无需自动口语可跳过。*

3. **配置 E听说 安装目录**
如果未检测到可用的E听说可运行程序，会提示配置安装目录。请在打开的选择框里选择E听说的安装根目录，从而完成后续操作。

4. **配置答题设置**
完成以上初始化后，就可以开始测试了。可以在 etstool 左侧选择答题设置标签页，从而配置目标正确率、跳题间隔、口语模式、自动启动监听器、自动口语，以及重新配置/删除凭据。配置完成后，按下保存以确认偏好设置。

## 使用 etstool

本段将会介绍在完成上述配置后如何使用 etstool。

注：为正常使用 etstool，请使用管理员权限运行此程序。
若 Windows SmartScreen 提示，请点击仍然运行。
本程序不包含任何病毒文件，后台任务也仅存在监听器进程。

在首页可以看到初始化、启动并切换到程序预览按钮，点击将会启动E听说主程序并切换到程序预览标签页，在此可以看到E听说程序的小窗，用鼠标或触控进行操作。选择完试卷后，待解压完成资源包，在E听说点击开始答题即可使 etstool 开始自动答题。

### 选择题
etstool 将会自动完成选择题，并使用跳过按钮（如果可用）进行快速答题。每次尝试跳过的间隔时间受答题设置的跳题间隔控制，正确率受目标正确率控制。如答题时遇到意外问题（例如程序崩溃/闪退/进程被终止），请先在E听说中手动回到第一题，再在 etstool 中切回到主页，点击左侧手动重置重新开始答题。

### 口语题
在完成配置 DeepSeek 及 AliyunTTS 凭据及虚拟麦克风/扬声器驱动后，每次试卷开始时将会出现一个小窗，并会显示当前每个小题的文本转语音音频生成情况。如果生成完毕，即可正常在调用虚拟麦克风时播放。

**注意：在使用自动口语时，会出现物理扬声器没声音的情况，此属正常现象，在完成口语关闭 etstool 后会切回物理扬声器。**

答题设置中存在两种口语模式：

**`生成模式`** 对应提取题干后接入 DeepSeek，通过特定prompt生成回答，随后使用 AliyunTTS 转写为音频，通过虚拟麦克风输入E听说；

**`标答模式`** 对应直接提取标准答案并通过 AliyunTTS 转写为音频，无需 DeepSeek 生成回答。

### 试卷解析

在配置 DeepSeek 凭据后，可以在试卷选择界面将试卷发送给 DeepSeek 进行试卷解析，成功后会在用户下载文件夹保存 pdf，并在程序内显示 pdf 解析预览。

## 常见问题

### Q1: 找不到新版助手。请保留完整的_winui程序目录。
该问题通常是因为未通过管理员权限运行程序。尝试 exe 右键→以管理员身份运行，即可解决该问题。

### Q2: 未填写有效的凭据，无法完成指定操作？
在 DeepSeek 口语生成、试卷解析或阿里云语音合成时出现此提示，是因为对应的个人凭据尚未配置。点击“去填写”可跳转到答题设置，保存凭据后重试。

### Q3: `Unhandled exception in script...`?
该问题通常是因为程序错误或文件损坏导致的，请联系作者或在 GitHub 上提出 issue 。
